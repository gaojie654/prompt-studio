## 一、产品概述

### 1.1 产品定位
AI提示词生成工具，为电商卖家和自媒体创作者提供营销图片生成服务。

### 1.2 目标用户
- 电商卖家（淘宝/拼多多/京东）
- 自媒体运营者（小红书/抖音/公众号）
- 需要营销素材的中小企业

### 1.3 核心价值
用户上传产品图 + 输入需求 → AI生成多平台营销图片
